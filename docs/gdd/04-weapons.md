# 4. Оружие

[← Оглавление](README.md)

## 4.1. Общие принципы

- Три категории: **общее** (доступно обеим командам), **только оборона**, **только атака**.
- У каждого предмета есть **прочность** (см. [Механики](06-mechanics.md#61-прочность-оружия)). Сломанное оружие ближнего боя бьёт на 30 % урона и не блокирует, дальнобойное не стреляет.
- Снаряды (стрелы, болты, бомбы, ядра, камни) конечны и пополняются в комнатах припасов (у обороны) и у повозок (у атаки).
- Стартовое оружие доступно всем бесплатно; остальное покупается за монеты и прокачивается (см. [Экономика](07-economy.md)).

### Снаряжение (лоадаут)

| Слот | Что кладётся | Пример |
|------|--------------|--------|
| 1. Основное | Любое оружие ближнего боя или дальнобойное двуручное | Длинный меч, алебарда, длинный лук |
| 2. Вторичное | Одноручное ближнее или лёгкое дальнобойное | Кинжал, короткий лук, праща |
| 3. Метательное | Один тип метательного | Бомбы ×3, метательные топорики ×2 |
| 4. Командный слот | Щит (оборона) или осадный инструмент (атака) | Павеза / крюк-кошка |
| Инструмент | Всегда есть, не занимает слот | Молоток ремонта (оборона), кувалда-лом (атака) |

Стационарные машины (пушки, катапульты, баллисты, котлы) в слоты не входят, ими пользуются на месте.

Типы урона: **рубящий** (хорош против незащищённых), **колющий** (пробивает блок частично, хорош по щитам не очень), **дробящий** (оглушает, наносит урон щитам и конструкциям ×2), **взрывной** (урон по площади, разрушает стены), **огонь** (урон со временем, поджигает дерево).

## 4.4. Общее оружие: метательное взрывное

|---------|------|--------|-------------|

| Улей с пчёлами (редкий) | 3/с | Рой 4 м, 10 с | Рой преследует ближайшего врага, мимика паники. Выпадает только из ящиков припасов |

### 4.4.1. Случайный таймер бомбы

Бомба поджигается при подготовке к броску (игрок видит искрящийся фитиль), а время до взрыва **случайно и скрыто**:

- **85 %** бросков: взрыв через **3–6 с** (равномерно);
- **15 %** бросков — «сюрприз», поровну делится:
  - **7,5 %**: взрыв через **0–3 с** (может рвануть прямо в руке);
  - **7,5 %**: взрыв через **7–15 с** (бомба долго катается по полу, и все нервничают).

```csharp
// Выполняется на сервере в момент поджига
float RollFuseTime(System.Random rng)
{
    double roll = rng.NextDouble();
    if (roll < 0.85)  return Lerp(3f, 6f,  rng.NextDouble());   // обычный
    if (roll < 0.925) return Lerp(0f, 3f,  rng.NextDouble());   // ранний
    return                 Lerp(7f, 15f, rng.NextDouble());     // поздний
}
```

Правила:
- Таймер считает **сервер**, клиентам он не передаётся (чтобы не было читов с «видно таймер»).
- Фитиль визуально сгорает с одинаковой скоростью для всех бомб и не выдаёт реального времени. Последние 0,5 с перед взрывом бомба раздувается и шипит громче: это честное предупреждение для всех.
- Бомбу можно держать в руке сколько угодно (фитиль горит). Взрыв в руке наносит полный урон бросающему.
- Бомбу можно **пнуть** или **отбить** ударом ближнего боя обратно (силовой удар дробящим оружием отбивает дальше).
- Упавшую, но не взорвавшуюся бомбу можно подобрать и бросить снова. Таймер при этом не перезапускается.
- Бомбу можно потушить, бросив её в воду (ров, колодец, бочка с водой).
- Пораженные взрывом получают мимику «копоть» (чёрное лицо, взъерошенные волосы) на 3 с.

## 4.7. Осадные машины: общие правила

- Машина принадлежит команде, управлять может любой игрок этой команды.
- Урон по машинам: огонь и ядра наносят полный урон, мечи 10 %, топоры и молоты 50 %.
- Машина горит, если её поджечь: 20 урона/с, пока не потушат (ведро воды у повозки).
- Уничтоженная машина остаётся обломками (укрытие) и возрождается у шатра по таймеру.
- Лимит одновременно существующих машин атаки: 3 катапульты, 3 тарана, 1 осадная башня, 6 мантлетов.

## 4.8. Прокачка оружия (кратко)

Каждое оружие имеет 5 уровней. Уровни повышают прочность, скорость перезарядки и немного урон (максимум +10 % на 5-м уровне), а также открывают косметику (гравировка, цвет). Подробные цены и шаги в разделе [Экономика](07-economy.md#73-прокачка-оружия).
