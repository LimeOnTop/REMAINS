# 8. Меню и интерфейс

[← Оглавление](README.md)

## 8.1. Главное меню

**Фон:** замок в 3D (реальная сцена карты или её облегчённая копия) на закате, флаги колышутся, над башнями кружат птицы. К сцене применён **размытый фон** (depth of field): замок слегка заблюрен. На **ближнем плане** (слева или справа от кнопок) стоит персонаж игрока в полной кастомизации и с выбранным оружием.

Поведение персонажа в меню:
- idle-анимации: переминается, чешет затылок, зевает, роняет и поднимает шлем;
- следит глазами за курсором;
- при наведении на «Играть» принимает боевую стойку, на «Кастомизацию» разглядывает себя, на «Настройки» достаёт очки;
- клик по персонажу вызывает случайную эмоцию (и мимику «ой!»).

**Кнопки (в столбик):**
1. **Играть**
2. **Кастомизация**
3. **Настройки**
4. Выход (мелко, внизу)

Вверху справа: монеты, уровень, ник, кнопка друзей/группы.

## 8.2. «Играть»

Подменю поверх того же фона:
- **Быстрая игра**: автоматический подбор матча 30 на 30.
- **Создать матч**: приватная комната, настройки (цель: принцесса / сокровище / случайно; число игроков; жизни атаки; таймер; эксперименты: двойной прыжок). Код комнаты для друзей.
- **Войти по коду**.
- **Список матчей** (браузер сессий).
- **Тренировочный двор** [Позже]: карта без врагов для опробования оружия и манекенов.

Технически ложится на существующие блоки проекта: `QuickJoin`, `CreateSession`, `JoinSessionByCode`, `SessionBrowser` (см. [Техническая часть](09-tech.md)).

## 8.3. «Кастомизация»

Камера подъезжает к персонажу (фон ещё сильнее размывается). Вкладки:
1. **Персонаж**: тело, лицо, голова, накидка, герб, голос, надгробие.
2. **Оружие (арсенал)**: список оружия по категориям (общее / оборона / атака), покупка, прокачка по уровням, просмотр характеристик, сравнение двух предметов. Персонаж на экране держит выбранное оружие и делает пробный замах.
3. **Лоадауты**: сохранённые наборы снаряжения отдельно для обороны и для атаки.
4. **Эмоции**: колесо эмоций.

Перед покупкой можно примерить предмет. Цена и остаток монет показываются внизу.

## 8.4. «Настройки»

| Раздел | Пункты |
|--------|--------|
| Графика | Разрешение, режим окна, качество (низкое / среднее / высокое / ультра), дальность прорисовки, тени, размытие в меню, FOV (70–110), лимит FPS, V-Sync |
| Звук | Общая громкость, музыка, эффекты, голоса персонажей, голосовой чат, устройство микрофона, push-to-talk / всегда включён |
| Управление | Чувствительность мыши и стика, инверсия Y, переназначение клавиш, вибрация геймпада, режим приседа (удержание / переключение), режим бега |
| Интерфейс | Масштаб HUD, цвет прицела, показ урона числами, мини-карта (вращается / фиксирована), субтитры |
| Доступность | Интенсивность тряски камеры (0–100 %), покачивание камеры вкл/выкл, дальтонизм (фильтры команд), уменьшение вспышек |
| Язык | Русский, English |

## 8.5. Экран смерти и выбора шатра

**Атака (после смерти):**
- 2 с камера смотрит на убийцу (его ник, оружие, его мимика торжества).
- Затем открывается **тактическая карта сверху** с тремя шатрами (фронт, левый, правый).
- Карточка каждого шатра: число живых союзников рядом, осадные машины на стоянке, заполненность повозки припасами, значок «под угрозой», таймер следующей волны.
- Поверх карты нарисован план со столов планирования.
- Выбор: клик по шатру (или стрелки/стик). Текущий выбор подсвечен. Внизу: «Возрождение через 7… в ПРАВОМ шатре. Осталось жизней: 143».
- Во время ожидания можно сменить лоадаут (он применится при появлении).

**Оборона:** камера на убийцу, затем вид на площадь сверху с таймером возрождения, сменой лоадаута и состоянием стен.

## 8.6. HUD в матче

```
┌───────────────────────────────────────────────────────────────┐
│ [🛡 ОБОРОНА]   ⏱ 11:42   ⚔ ЖИЗНИ АТАКИ 143/200   [АТАКА ⚔]   │
│  Ворота 64%  |  З-стена 100%  |  В-стена ПРОЛОМ  |  Цель: 👑  │
│                                                               │
│                         (события и убийства справа сверху)    │
│                                                               │
│                              +                                │
│                                                               │
│ ┌────┐                                          ┌───────────┐ │
│ │ :) │ ❤ 78  ▮▮▮▮▮▯ выносл.            [1] Длинный меч 72% │ │
│ └────┘  портрет с мимикой               [2] Лук 🏹 14/15     │ │
│  мини-карта                             [3] 💣 ×2            │ │
└───────────────────────────────────────────────────────────────┘
```

- **Верх:** таймер, жизни атаки, состояние ключевых укреплений, статус цели (на месте / несут / лежит).
- **Лево-низ:** портрет с мимикой, здоровье, выносливость, мини-карта.
- **Право-низ:** слоты оружия с прочностью (цвет полоски) и боезапасом.
- **Центр:** прицел, контекстные подсказки взаимодействия с прогресс-кругом, индикатор натяжения лука, индикатор попадания.
- **Маркеры в мире:** цель, союзные осадные машины, пинги, кузнец и комнаты припасов (при приближении), значок «очередь у кузнеца».
- **Уведомления:** «Главные ворота пробиты!», «Принцесса похищена!», «Осталось 50 жизней!», «Пороховой погреб взорван!».

## 8.7. Экран итогов

- Большой баннер «ПОБЕДА» / «ПОРАЖЕНИЕ» с комичной сценой (атака победила: принцесса в клетке на повозке недовольно машет; оборона победила: атакующие бегут, принцесса показывает язык).
- Табло обеих команд: убийства, смерти, помощь, ремонт, урон по укреплениям, очки.
- MVP каждой команды: 3D-персонаж на пьедестале с эмоцией победителя.
- Начисленные монеты с разбивкой, прогресс уровня.
- Кнопки: «Ещё раз» (голосование, команды меняются сторонами), «В меню».
