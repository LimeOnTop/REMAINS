## 9.1. Что уже есть в проекте

Проект Unity 6000.6.3f1 собран на шаблоне Multiplayer Building Blocks. В репозитории сейчас:

| Модуль | Путь | Как пригодится |
|--------|------|----------------|
| Netcode for GameObjects 2.13, Multiplayer Services 2.3 | `Packages/manifest.json` | Сетевая основа матча, лобби и подбор игроков |
| Сессии (QuickJoin, CreateSession, JoinSessionByCode, SessionBrowser) | `Assets/Blocks/MultiplayerSession` | Меню «Играть» (8.2) |
| Core (игрок, передвижение, статы, взаимодействия) | `Assets/Core` | Передвижение от первого лица, взаимодействие `E` (ModularInteractable), статы (здоровье, выносливость) |
| Platformer (DoubleJumpAbility, эффекты) | `Assets/Platformer` | Основа для экспериментального двойного прыжка/сальто (3.6) |
| Shooter (ModularWeapon, ModularProjectile, ArcMovement, ExplosiveEffect, AmmoHandler, WeaponLoadout) | `Assets/Shooter` | Дальнобойное оружие, баллистика стрел и ядер, взрывы, боезапас, лоадауты |

Основная сцена игры `Remains_Castle` (с NetworkManager, GameManager, MatchManager, MatchHUD, LoadoutMenu, VoiceChat) существует локально у автора и пока не в репозитории.

## 9.2. Сеть на 60 игроков

- **Модель:** выделенный сервер или хост с авторитетом сервера. Для 60 игроков рекомендуется выделенный сервер (Multiplay / собственный), хост-режим только для приватных матчей до ~16 игроков.
- **Авторитет сервера** над: уроном, прочностью, таймером бомб, жизнями атаки, состоянием стен, позицией цели, запасами припасов.
- **Клиентское предсказание:** передвижение, анимации замаха, визуальные эффекты. Попадания ближнего боя проверяются на сервере с компенсацией задержки (lag compensation, откат до 200 мс).
- **Оптимизация трафика:** Interest management / видимость по дистанции (игроки дальше 80 м реплицируются реже), сжатие трансформов, отдельные частоты тиков (игроки 30 Гц, конструкции только по событиям).
- **Разрушения:** состояние элементов (HP и стадия) синхронизируется целым числом; обломки чисто визуальные и клиентские.
- **Катсцены:** запускаются RPC от сервера со слотами игроков; управление включает сервер по окончании.
- **Голос:** Vivox (сейчас не инициализирован: проект не привязан к Unity Cloud, нужно привязать проект в Services и включить Vivox в Cloud Dashboard).

## 9.4. План прототипа (вертикальный срез)

1. **Серый бокс замка:** стены 3 этажа, одни ворота, одна калитка, донжон, площадь, один шатёр. Без интерьеров.
2. **Бой:** меч, топор, лук, бомба, круглый щит. Прочность и кузнец.
3. **Цель:** принцесса, перенос, зона доставки, таймер, жизни.
4. **Осада:** таран, ворота с ремонтом, лестницы.
5. **Плейтест 8 на 8** с масштабированием жизней, затем 30 на 30 с ботами/тестерами.
6. По итогам: катапульта с полётом игроков, три шатра, комнаты припасов с похищением, мимика.
